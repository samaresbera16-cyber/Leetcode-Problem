# LeetCode Python Solutions — Problems 1–5

Simple, beginner-friendly Python solutions for the five competitive programming problems in the assignment PDF.

## Problems
1. **Single Number** — Bit Manipulation (XOR)
2. **Remove Duplicates** — Hash Set, preserving first-occurrence order
3. **Binary Search in a Descending Array** — Binary Search
4. **Two Sum** — Hash Map (Dictionary)
5. **Valid Parentheses** — Stack

## How to run
Make sure Python 3 is installed. Open a terminal in this folder and run a file, for example:

```bash
python 01_single_number.py
```

Each program reads input from the user using `input()` and prints the answer.

## Note
These are standalone programs for local practice. LeetCode's submission editor usually expects a `class Solution` method rather than user-input statements.
